=== Presentación del proyecto ===

En este repositorio encontrarán tres carpetas:
-src: contiene los tres archivos .java con el codigo fuente
-bin: contiene los archivos .class con el bytecode generado tras la compilación de los programas
-docs: Aquí encontrarán el reporte de la práctica, junto con la carpeta images, que contiene 
capturas de pantalla de las ejecuciones de los tres programas.

El primer programa, PiInteractivo, pide al usuario un número de dardos para calcular Pi con
el método Monte Carlo.

El segundo, BinarioInteractivo, pide al usuario un número para convertirlo a binario.

El tercer programa es un cotizador de préstamos con interés simple y compuesto, que permite
guardar el nombre del cliente, su nivel de confianza, los meses del préstamo, etc.

Para ejecutar cualquiera de estos programas, muévete a la carpeta Practica06 y teclea en la
terminal 'javac -d bin .../rutaDelArchivo/nombreDelPrograma.java', esto compilará el programa.
Ahora, da enter  y teclea 'java -cp bin nombreDelPrograma'. El programa se comenzará a ejecutar
en tu terminal.
